# PostGen

Flask-приложение для генерации постов из лонгридов с помощью LLM (GigaChat) с публикацией в ВКонтакте.

## Быстрый старт

1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   cd postgen
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   source venv/bin/activate  # macOS/Linux
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Настройте переменные окружения:
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` и укажите:
   - `GIGACHAT_CLIENT_SECRET` — base64-строка ключей GigaChat
   - `VK_ACCESS_TOKEN` — токен сообщества ВК
   - `VK_GROUP_ID` — ID вашего сообщества ВК

5. Запустите приложение:
   ```bash
   python app.py
   ```

6. Откройте в браузере: [http://127.0.0.1:5002](http://127.0.0.1:5002)

## Как подключить ВКонтакте (простыми словами)

Чтобы публиковать посты в ваше сообщество ВК, нужно получить **токен доступа** и **ID группы**.

### Что нужно:
1. **VK_ACCESS_TOKEN** — ключ, который разрешает приложению писать от имени сообщества.
2. **VK_GROUP_ID** — номер вашего сообщества (берется из URL).

### Где взять:
1. Зайдите в ВК → **Управление сообществом** → выберите сообщество.
2. Перейдите в **Работа с API** → **Ключи доступа**.
3. Нажмите **Создать ключ** (нужны права: `wall` — стена, `groups` — сообщества).
4. Скопируйте ключ — это и есть `VK_ACCESS_TOKEN`.
5. **ID группы** — это цифры из URL вашего сообщества: `vk.com/public123456` → ID = `123456`.

### Куда добавить:
Откройте файл `.env` и добавьте:
```
VK_ACCESS_TOKEN=скопированный_ключ
VK_GROUP_ID=123456
```

Перезапустите сервер — теперь кнопка "Опубликовать" будет работать!

## Возможности
- Генерация постов из лонгридов (до 2000 символов)
- Публикация в ВКонтакте (сразу или отложенно)
- Сохранение постов в избранное
- Копирование одним кликом

## Требования
